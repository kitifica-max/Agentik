# Kogn — Design System Brief

Fuentes: 3 ilustraciones line-art de referencia (ventanas retro, estrellitas, cursor, globos, stickers) + board Pinterest compartido (~247 pins; UI de apps con acento gris/amarillo neón sobre negro/blanco).

## Tokens
- Tinta `#141414` / papel `#fff`. Dark: tinta `#f4f4ee` / papel `#161616`.
- Acento único `--pop: #e4e4e4` (gris claro), solo para estados activos, propuestas y hover. Pins: acentos neón sobre base monocroma.
- Trazo `--stroke: 2px` sólido en todo. Radios: 8px botones, 12px tarjetas/mensajes, 999px pestañas e input.
- Sombra dura sin blur: `2–3px 2px 0 var(--ink)`. Sin degradados.

## Patrones
- Ventana = barra superior con 3 puntos + ✦ (ilustración 1).
- Mensaje usuario: relleno tinta. Asistente: contorno + sombra dura.
- Botón: contorno; hover gris + desplaza -1px; active +1px sin sombra.
- Pestaña activa: relleno tinta. Items activos/aprobados: relleno gris.
- Estado vacío: ilustración line-art (ventana + carita + cursor).

## Pendiente
Ilustraciones por sección (Memoria, Archivos, Ajustes) y estados de error estilo diálogo retro ("Error / OK").
